# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good faith, and keep discussion about the work. Harassment of any
kind is not tolerated. Report unacceptable behaviour to the maintainer,
[@tkabala](https://github.com/tkabala); reports are handled confidentially.
